# Minhas Finanças

Web app minimalista (tema escuro) para organizar finanças pessoais:

- Renda mensal + budgets por categoria em %
- Investimento obrigatório descontado do saldo
- Gráficos (distribuição e orçado × realizado)
- Transações com busca e filtro
- PWA instalável no iPhone/Android, funciona offline

Abra `index.html` ou acesse via GitHub Pages.
